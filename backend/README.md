# Dhaka Tesla Pool

> Share a seat. Split the fare. Survive Dhaka traffic.

## Overview

Dhaka Tesla Pool is a ride-pooling MVP application that allows passengers to share Tesla rides, split fares, and manage pooled trips efficiently.

The system connects passengers travelling in compatible directions with available Tesla vehicles while maintaining seat capacity, ride status, and fare management.

This project is developed as a full-stack application with a focus on clean backend architecture, database design, testing, and deployment practices.
